# osa-demo

税理士法人おかやま創研様向け 分析システム「OSA」の公開デモ（静的HTML）。

- 公開URL: https://genesis-dev-8.github.io/osa-demo/
- ログイン: `demo` / `demo1523`

## データについて

金額・件数・労働時間・集計ロジックは **2026年7月の実データ** を使用していますが、
**関与先名・担当者名・個人名・kintone IDはすべて匿名化** しています（関与先は「株式会社 サンプル001」、担当者は「担当者01」等）。
実在の企業名・個人名は含まれません。

## 構成

`index.html` 1ファイルのみ。ビルド不要、ブラウザで開くだけ。

## 元データ（匿名化前）

実データ版は非公開リポジトリおよび限定配信で管理しています。本リポジトリには含めません。
