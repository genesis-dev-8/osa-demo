# osa-demo

税理士法人おかやま創研様向け 分析システム **OSA (Okayama Soken Analytics)** の公開デモ（静的HTML）。

- 公開URL: https://genesis-dev-8.github.io/osa-demo/
- ログイン: `demo` / `demo1523`

## データについて

金額・件数・労働時間・集計ロジックは **2026年6月・7月・8月の実データ** を使用していますが、
**関与先名・担当者名・個人名・kintone IDはすべて匿名化** しています
（法人は「株式会社 サンプル001」、個人は「個人001様」、担当者は「担当者01」等）。
摘要・備考に含まれていた故人名等も除去し、和暦は西暦へ正規化しています。
実在の企業名・個人名は含まれません。

取込元：FMS請求実績（岡山・倉敷）／kintone（業務日報・資産税請求・コンサル請求①②）／TKCマスタ①②

## 改修指示書（OSA Change Requests / 2026年9月）への対応

| ID | 内容 | 対応 |
|----|------|------|
| OSA-01 | 指標ごとの月次推移グラフ | 個人成績・ダッシュボード・日報連携に折れ線グラフを追加（報酬／直接時間／時間生産性／受託件数） |
| OSA-02 | 関与先表を月別列＋年間累計へ | 事業年度（11月〜翌10月）の月別列・年間累計・横スクロール。行クリックで業務分類内訳、金額クリックで請求明細 |
| OSA-03 | 事務所平均との比較 | 平均・中央値・差分％・意向額から逆算した必要時間単価を表示。「順位付けではない」旨を明記。担当者本人の画面にも表示 |
| OSA-04 | 年度累計の達成率 | 単月達成率と年度累計達成率を併記 |
| OSA-05 | システムレンタル料を個人から外す | 対象業務分類をマスタで指定し、シスサポチームへ集約。**対象の報酬細目コード一覧を画面に提示（要 客先確定）** |
| OSA-06 | コンサル報酬を個人帰属へ | kintoneコンサル①②を個人実績として集計。資産税・シスサポはチーム管理を継続 |
| OSA-07 | 組織マスタ階層での集計切替 | ダッシュボード／従業員別成績で 全社・オフィス・チームを切替。チーム別の生産性比較表を追加 |
| OSA-08 | 和暦の西暦統一 | 取込時に日付・摘要の和暦を西暦へ正規化 |
| OSA-09 | 英語ラベルの日本語化 | ヘッダー・メニュー・KPI・権限表示をすべて日本語へ |
| OSA-10 | 製品名「OSA」の適用 | ヘッダー・タイトル・ログイン画面に適用 |
| OSA-11 | 配色を明るく | 青系のまま明度を上げ、CSS変数（トークン）で一元管理（将来の状態別配色に対応可） |
| OSA-12 | 前月比を既定の比較軸に | 各KPI・業務分類内訳・従業員別成績に前月比を標準表示 |
| OSA-13 | 担当変更の検出 | 前月取込との差分を「移管／新規／当月請求なし」に区分して検出。担当者本人の画面と確認状況に表示 |
| OSA-14 | 目標入力を「意向」へ | 画面名を「来期の意向入力」に変更。ノルマではない旨・上長と合意する旨を明記（**文言は要 客先判断**） |
| OSA-15 | チェック・突合機能の継続 | 継続。月次推移の突合ビューを追加 |
| OSA-16 | 未分類レコードの明細表示 | 継続。611/612/613/996 の要確認内容を画面に明記 |
| OSA-17 | 報酬ランキングの公開 | 保留。実装可能な状態のまま非公開 |
| OSA-18 | 管理者メニューの集約 | 対応不要 |

### 要確認事項（9/25レビュー）

1. OSA-05：シスサポチームへ移す報酬細目コードの確定（チーム集計＞システムサポートチームに一覧を表示）
2. OSA-16：報酬細目コード 611 / 612 / 613 / 996 の業務分類割当
3. OSA-14：「意向額」「進捗率」の画面文言
4. OSA-17：報酬ランキングを表示するか
5. **事業年度の期首月**：改修指示書は4月〜3月表記、現行システムは11月〜翌10月。本デモは11月開始で実装（`fyStartMonth`）
6. OSA-13：TKC_CDBは最新1本のみのため、担当変更の検出はFMS請求実績で代替。月次スナップショットがあれば精度が上がります

## グラフの金額表記

各グラフの値ラベル・tooltip・現在値は、値の分布から表記を自動で決定し、1グラフ内で統一します。

- **10万円以上の値が過半数** → 千円単位＋「千円」接尾辞（例: `1,234千円`）
- それ以外 → 円のまま＋「円」接尾辞（例: `87,500円`）

対象は棒グラフ（業務分類別 報酬など）と推移折れ線（trendCard）。
KPIタイル・テーブル・モーダルは従来どおり接尾辞なしの千円単位表記。
